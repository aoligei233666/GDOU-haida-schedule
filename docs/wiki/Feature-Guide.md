# 核心功能使用指南

---

## 1. 教务无痕同步（校内 / 校外自适应）

点击课表右上角 **「无痕同步」**，应用自动探测 `https://netcheck.gdou.edu.cn/go.php?code=jw`，识别当前处于 **校园网直连（`jw.gdou.edu.cn`）** 还是 **校外微门户反代（`wfw.gdou.edu.cn`）**。

提供两种同步通道：
- **极速直连模式（推荐）**：输入学号与统一身份认证密码，本地使用 CSPRNG AES-128-CBC 加密后直连官方认证；若校外微门户或统一认证触发短信/企业微信多因子验证码（MFA），弹窗内直接输入验证码完成第二步鉴权即可一键拉取 **课表 + 节次作息 + 考试 + 历年成绩**。
- **官网无痕网页模式**：在独立无痕沙箱 WebView 中打开海大官方登录页（支持滑块验证、微信/短信免密登录），登录进入教务首页后点击底部提取按钮即可同步；关闭或完成后自动销毁 WebStorage 与原生 Cookie。

## 2. 周课表、多课查看与非本周切换

- **周次切换**：顶部左右箭头可翻阅第 1–20 周，非本周时显示 **「回本周」** 快捷胶囊。
- **非本周开关**：顶栏 **「非本周」** 按钮可一键显示或隐藏全学期非本周排课。
  - 非本周独立课程以灰底 `非本周` 标识展示，绝不误判为撞课；
  - 若当前周课程与他周课程共用同一节次，卡片底部以 slim 细条标注 **「含他周」**（不挤压课程名），点击卡片即可在弹窗顶部切换查看所有周次的排课。
- **同周重课（撞课）**：仅当同一人同一周存在时间重叠的两门及以上课程时才标示 `撞课N`，点击卡片弹窗支持左右翻页/标签切换。
- **手动加课**：点击课表任意空白网格、顶栏 **「+ 加课」** 或课程详情弹窗底部 **「在此时段再加一节课」** 即可新增自定义课程（支持自定义周次与单双周，并支持单独删除）。
- **校区作息自定义**：内置湖光校区（08:10 标准版 / 08:00 版）及阳江/海滨校区（08:20 版），同步时自动拉取教务实时节次时间，也可在「关于设置」中手动微调开学首周日期及第 1–12 节起止时间。

## 3. 情侣课表（零服务器双人同屏）

点击课表顶栏 **「情侣同屏」** 或齿轮图标进入情侣课表管理：

### 三种零服务器同步方式
1. **口令互传（最方便）**：对方生成以 `GDOU-COUPLE-V1:` 开头的纯课程口令（绝不含学号/密码），通过微信或 QQ 发给你后直接整段复制粘贴（自动忽略前后聊天文字）即可绑定。
2. **JSON 文件导入导出**：导出 `.json` 课表文件发给对方导入。
3. **面对面无痕代拉取**：对方亲自在你手机上使用无痕同步弹窗拉取其课表，拉取完立即注销销毁凭据。

### 双人专属视图与洞察
- **视图切换**：顶栏一键切换 **「我的」 / 「情侣同屏」 / 「TA 的课表」**。
- **共同空闲标记**：工作日白天两人均无课的大节自动以虚线框标注 **「♡ 共同没课」**（可在管理中开关）。
- **实时状态横幅**：顶部实时显示当下两人谁在上课、谁空闲、下课时间，以及本周 **同堂上课** 与 **顺路同楼** 统计。

## 4. 双端系统闹钟与系统日历

### 每日首课早起 / 课前 / 考前闹钟
- **Android**：
  - 点击「一键本周系统早起闹钟」、单节课前闹钟或考前闹钟时，通过原生 `AlarmClock.ACTION_SET_ALARM` **直接写入手机自带「系统时钟」**；
  - 每日首课起床闹钟会自动将相同唤醒时间点合并星期（例如周一/三/五均为 08:10 首课，只生成一条 `07:25 (一/三/五)` 系统闹钟）。
- **iOS**：
  - **iOS 26+**：原生调用 **Apple `AlarmKit`** 直接写入系统级闹钟服务，支持**锁屏全屏响铃**并**穿透静音开关与专注/勿扰模式**；每日早起按星期独立写入，可在应用内「闹钟日历」页逐条开关或删除，自动同步取消系统守护闹钟。
  - **iOS 15–18**：自动降级为每周循环系统铃声提醒（`defaultRingtone`），不会跳过本周已过星期。
- **幂等去重**：重复生成同一周/同一门课/同一场考试的闹钟时自动替换旧记录，杜绝重复响铃。

### 系统日历与 `.ics` 导出
- **原生系统日历同步**：自动创建独立日历 **「海大课表 (GDOU)」**（受限设备自动降级写入默认日历并按 `[GDOU-COURSE:...]` / `[GDOU-EXAM:...]` 标签隔离），原位更新日程，同步课表绝不误删考试，点击「移除专属日历」仅清理海大课表日程，绝不触碰个人日程。
- **RFC 5545 `.ics` 导出**：支持导出标准 `.ics` 文件（`Asia/Shanghai` 固定时区、75 字节 UTF-8 安全折行、稳定 UID），可导入 Apple 日历、Google 日历、Outlook、钉钉/飞书日历等任意日历软件。

## 5. 考试安排与成绩绩点仪表盘

- **考试查询**：自动拉取考试日期、起止时间、考场、座位号与倒计时，支持手动添加随堂测验并一键写入日历与考前双重提醒（前晚 20:00 + 考前出发闹钟）。
- **绩点学分仪表盘**：
  - **总览视图**：总平均绩点 GPA、必修课 GPA、加权均分、累计学分、通过率、分学期 GPA/学分对比表（点击直达该学期明细）、课程性质学分构成条形图、成绩分段分布。
  - **明细视图**：支持按学期、课程性质、未通过筛选，按课名/课号/教师搜索与多维排序；缺失原始绩点采用本地换算时会清晰标注 **「估算」**。
