# 常见问题与故障排查

---

## 1. 校外登录提示 `HTTP 403 Forbidden`

**原因**：海大校外微门户（`wfw.gdou.edu.cn`）Nginx WAF 会对海外代理出口 IP、或短时间内高频访问的同一宽带出口 IP 实施临时 403 封禁。

**解决方法**：
1. **关闭手机上的 VPN / Clash / 海外代理**（微门户通常拒绝非中国大陆 IP）。
2. 若在宿舍/家庭 Wi-Fi 下仍报 403，**暂时关闭 Wi-Fi 切换至手机 4G/5G 蜂窝流量** 重试（或重启路由器重新拨号换取新公网 IP）。

---

## 2. 校外登录时弹出二次认证（企业微信 / 短信验证码）

- **极速直连模式**：支持无缝在弹窗内直接输入第 2 步验证码完成微门户与教务子会话双阶段校验，无需切到浏览器。
- **官网无痕网页模式**：支持直接在页面内完成滑块、短信或企业微信验证，进入正方教务首页后点底部提取按钮同步即可。
- 如遇极速直连验证码频繁失败，直接切换至 **「官网无痕网页」** 同步即可。

## 3. iOS 系统闹钟设置与权限说明

- **iOS 26+ 用户**：
  1. 请确保安装的是 **v1.4.3 及以上完整 IPA 安装包**（不是仅通过旧版本热更），以便系统识别 `NSAlarmKitUsageDescription`。
  2. 首次点击生成早起/课前/考前闹钟时，请在系统弹窗中点击 **「允许」** 授予闹钟权限；若曾误点拒绝，可在提示框点 **「前往系统设置」**（或前往 `设置 → 海大课表 → 闹钟`）重新打开。
  3. 写入的闹钟属于 iOS 原生 `AlarmKit` 系统级闹钟，响铃时自动锁屏全屏弹出并穿透静音与专注模式；但苹果系统规定 `AlarmKit` 闹钟**不会显示在苹果自带「时钟」App 列表内**，请直接在本应用 **「闹钟日历」** 页管理（开关/删除会实时同步系统守护进程）。
- **iOS 15–18 用户**：
  - 系统尚未提供 `AlarmKit`，应用会自动降级为每周循环系统铃声通知（`defaultRingtone`），请确保允许本应用发送通知并开启声音提醒。
- **为何点击「打开系统时钟」在 iOS 18/26 无跳转？**
  - 苹果从 iOS 18 起拦截了第三方 App 调用 `clock-alarm://` 的跳转链接，本应用已改为直接弹出说明并支持一键进入系统设置检查权限。

## 4. Android 系统闹钟与日历常见疑问

- **早起闹钟写入在哪里？** 直接写入手机自带的「时钟 / 闹钟」应用内，支持锁屏、后台清理与勿扰模式下准时响铃。
- **国产手机（MIUI/HyperOS、ColorOS、HarmonyOS 等）系统日历看不到「海大课表 (GDOU)」？**
  - 部分国产 ROM 限制第三方新建独立本地日历，应用检测到后会自动兼容写入默认可写日历，并给每条海大日程打上 `[GDOU-COURSE:...]` / `[GDOU-EXAM:...]` 标识，清理时仍只移除海大日程，不影响其他日程。
  - 若系统日历中未勾选显示，请打开手机自带日历的「日历账户/显示管理」确认勾选了 `海大课表 (GDOU)`。

---

## 5. 周次或上课时间不准怎么校准？

1. 进入 **「关于设置」**：
   - 核对 **「本学期第一周周一日期（开学基准日）」**，修改后整学期周次与日历/闹钟日期立即重新对齐。
   - 根据所在校区选择 **湖光校区（08:10 / 08:00）** 或 **阳江/海滨校区（08:20）**，也可点击 **「编辑节次时间」** 自定义第 1–12 节每一节的起止时间。

---

## 6. 软件内「检查更新」提示网络慢或 GitHub 限流

- 校园网共享公网 IP 有时会触发 GitHub API 匿名限流（HTTP 403/429），应用内置了自动回退通道（自动拉取仓库 `altstore-source.json` 元数据），一般等待几秒即可获取最新版本。
- 若下载大体积 APK/IPA 较慢，可切换手机流量或在浏览器中访问 [GitHub Releases](https://github.com/aoligei233666/GDOU-haida-schedule/releases) 下载。
